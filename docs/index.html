Smarter car rental offers for every travel partner

When someone books a flight or a stay, they are offered a car. This app decides the price and the order of those cars for each traveller, so more cars get booked at a better profit, while every partner keeps its own rules. It is an independent portfolio project, built on simulated data.

Simulated data. All customers, prices, revenue shares and limits are invented assumptions. Partner names only label scenarios. They are not real contract terms or data, and this project is not affiliated with or endorsed by any named company.
1Predict

A model learns how likely each traveller is to book each car, from the car, the price, the position on screen and who the traveller is.

2Decide

For every traveller it tries many prices and orders in a split second and keeps the one with the best expected profit.

3Protect

Each partner sets its own limits: how high prices may go, and how many bookings it will not give up. The engine never crosses them.

How it runs

GitHub Actions: tests, lint, train, build→ Amazon ECR image→ ECS Fargate service→ POST /rank · /health · /metrics
  • The API takes a partner session and a list of cars, and returns prices and order in about 20 ms, applying that partner's markup limits and booking value.
  • The model is a logistic regression stored as JSON, so serving needs only numpy.
  • 28 automated tests cover the simulator, model, optimiser, A/B harness, drift monitor and API.

Limits of this work

  • Everything is simulated. The hidden customer model is a logit, which favours a logistic regression. On real data the neural network or boosting could win.
  • The "tuned rules" baseline can see the true expected margins, so it is a generous comparison. It still loses to the engine.
  • The gain from ordering assumes position effects can be learned from exploration logs. Real traffic would need a randomised logging policy first.
  • Per-partner limits, floors and the 30% revenue share are assumptions chosen for the demonstration.
Numbers on this page come from one full run of the evaluation script on simulated sessions. Observed A/B results include sampling noise; exact figures are computed analytically on the same sessions.
